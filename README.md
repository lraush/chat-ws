# Chat WS

Простой веб‑чат для общения в небольших группах.

Войдите под своим аккаунтом, создайте комнату или перейдите по приглашению. Ссылку можно отправить друзьям — они попадут в тот же разговор. Сообщения появляются сразу у всех участников комнаты.

Для комнаты можно задать «секретное число»: тогда переписка отображается в зашифрованном виде, пока вы не введёте это число на входе в чат.

В меню доступны профиль и выход из аккаунта. Администратор может добавлять новых пользователей — регистрация с сайта не предусмотрена.
